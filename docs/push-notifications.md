# Push-Benachrichtigungen

Das Mitarbeiterportal registriert Push-Benachrichtigungen erst nach ausdrücklicher Zustimmung des angemeldeten Nutzers.

- Nach einer erfolgreichen Anmeldung wird die Push-Einrichtung erneut geprüft, ohne dass die Seite neu geladen werden muss.
- Beim Abmelden werden sichtbare Push-Steuerelemente aus der Oberfläche entfernt.
- Ein bestehendes Geräte-Abonnement wird beim Nutzerwechsel serverseitig dem neu angemeldeten Nutzer zugeordnet, sobald Benachrichtigungen aktiviert oder synchronisiert werden.
- Auf iPhone und iPad ist für Web Push die installierte Home-Screen-Web-App erforderlich.
